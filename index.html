Recent Projects

I build things end-to-end — from multi-agent AI systems for clinical research to live SaaS platforms and computational biology pipelines. Most of my work sits at the intersection of agentic AI and life sciences, where I care about both the engineering rigor and the real-world impact.

AI Patient Actor — Fu Lab, UCLA Neurology

A dual-model agentic AI system for clinical medical education. One LLM instance maintains a standardized patient persona with Functional Neurological Disorder across open-ended conversations with neurology residents; a second acts as an autonomous LLM-as-judge evaluator scoring performance against a validated 7-criterion rubric. Designed with a blind evaluation architecture to prevent cross-agent anchoring bias. Built in Python using the OpenAI API under full IRB compliance.

Stack: Python · OpenAI API (GPT-4o-mini) · LLM-as-Judge · IRB-regulated

Math Nest — AI Math Learning Platform

A live, full-stack AI-powered math learning platform. Features a two-model AI generation pipeline with a semantic classifier routing queries to the appropriate model, Redis caching, rate limiting, and a multi-tier auth system (OAuth + magic link). Built with React, Node.js serverless functions, Supabase PostgreSQL, and Upstash Redis. Deployed on Vercel with a custom domain.

Stack: React · Node.js · PostgreSQL · Redis · Llama 3.3 70B · Vercel

Live at mathnest.org →

Sarcomere Repair Optimizer

A computational pipeline modeling protein assembly sequences for muscle repair optimization. Uses a directed graph (NetworkX DiGraph) with edges weighted by published binding affinity constants and Arrhenius kinetics. Integrates Boltz-2 (2024) for protein structure prediction. Config-driven via YAML with full separation of concerns across ingestion, modeling, simulation, and optimization layers. 27-test pytest suite with full acceptance criteria traceability.

Stack: Python · NetworkX · Boltz-2 · PyTorch-ready · Pytest · Jupyter

Agentic Security Pipeline

A multi-layer AI governance architecture built at the Sundai hackathon. A retrieval proxy controls what data reaches AI tools before generation; output guardrails filter unsafe content; action controls prevent unauthorized downstream behaviors. Designed to protect personal productivity apps from sensitive data exposure and cross-prompt injection.

Stack: Python · Claude SDK · Retrieval Proxy · Hackathon
